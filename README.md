# 悟空书签同步xbel-ByWebdav

使用 **XBEL** 格式通过任意 WebDAV 服务同步浏览器书签的 Chrome/Edge 扩展（支持 Firefox 类似 API）。

专为 123 云盘 WebDAV 等服务优化，也兼容其他 WebDAV（Nextcloud、ownCloud、自建等）。

## 特点
- **XBEL 格式**（参考 Floccus 成熟实践），结构保留更好、跨浏览器更稳
- 清晰的同步反馈：显示「从云拉取」与「推送本地」数量
- 支持手动「立即同步 / 仅导出 / 仅导入」
- 配置保存后自动测试连接
- 冲突处理：URL 相同则按标题更新（简单可靠）
- 纯前端扩展，无需服务器端

## 安装
1. 下载整个文件夹
2. Chrome 打开 `chrome://extensions/`
3. 开启「开发者模式」
4. 「加载已解压的扩展程序」 → 选择本文件夹

## 使用（以 123 云盘为例）
1. 在 123 云盘 WebDAV 里新建文件 `bookmarks.xbel`（必须是文件，不是目录）
2. 插件里填完整地址：
   ```
   https://webdav.123pan.cn/webdav/bookmarks.xbel
   ```
3. 输入你的 123 云盘账号密码（或应用密码）
4. 保存配置 → 测试连接
5. 点击「立即同步」

**重要**：URL 必须指向**具体文件**（.xbel），不能只到文件夹，否则会出现 405。

## 为什么用 XBEL 而不是 HTML？
- XBEL 是标准书签交换格式，Floccus 等成熟工具在 WebDAV 上默认使用
- 结构化更好，文件夹/标题保留更完整
- 跨浏览器导入导出更可靠

## 隐私
- 所有数据仅在你的浏览器和指定的 WebDAV 之间传输
- 代码中**无任何硬编码密码、Token 或个人信息**
- 仅使用你手动输入的 WebDAV 地址 + 凭证（保存在浏览器 storage）

## 构建 / 发布
无需构建，直接作为解压扩展加载即可。

如需打包 crx，可使用 Chrome 的「打包扩展程序」功能。
