# 悟空书签同步 xbel-ByWebdav

通过任意 WebDAV 云盘在 Chrome / Edge / Firefox 之间**共享书签**。

专为 123 云盘、坚果云等 WebDAV 服务优化，也兼容 Nextcloud、ownCloud、自建等。

---

## ⚠️ 共享模式 vs 合并模式

本扩展采用 **「共享模式」**：

```
云端 XBEL 文件 = 唯一真相
    ↙              ↘
Chrome 书签      Edge 书签
（都是云端的镜像）  （都是云端的镜像）
```

| | 共享模式（本项目） | 合并模式（Floccus） |
|---|---|---|
| **数据模型** | 云端是唯一真相，所有浏览器都是镜像 | 各浏览器各自独立，云端做汇集池 |
| **拉取** | 清空本地 + 从云端重建 | 云端补缺到本地（不删本地独有） |
| **推送** | 本地完全覆盖云端 | 本地并入云端（不删云端独有） |
| **删除** | 支持：推/拉都会删掉另一端删除的书签 | 不支持：即使一端删了，另一端同步后又会回来 |
| **冲突处理** | ETag 乐观锁阻止并发覆盖 | 依赖时间戳/snapshot 检测 |
| **适合谁** | 一个人维护一套书签，多设备共用 | 多人/多设备各有各的书签，需要互相补缺 |

**如果你需要「合并模式」（合并 = 多设备互相补缺、永不删除、各保留各的）——请使用 Floccus：**

> https://github.com/marcelklehr/floccus

Floccus 是书签同步的事实标准，支持 6 种存储后端、E2E 加密、移动端 App。本项目的定位是 Floccus 的**轻量替代品**——只做共享模式、零依赖、一键安装。

## 工作原理

两个按钮，两个方向，一切清晰：

| 按钮 | 操作 | 数据流向 | 何时用 |
|------|------|----------|--------|
| **同步到云端** | 本地覆盖云端 | 本地 → 云端 | 日常使用，改了书签就点 |
| **从云端恢复** | 云端覆盖本地 | 云端 → 本地 | 新设备初始化，让本地跟云端一样 |

**「同步到云端」**会将你当前的书签完整推送到云端，同时：
- 带 ETag 版本号，防止两台设备同时推送互相覆盖
- 安全阈值：本地书签若不足云端的 10%，会拒绝推送（防误删）

**「从云端恢复」**使用**增量 diff**——不再清空全部本地再重建，
而是逐条比对云端 XBEL 和本地书签，只做必要的操作：
- 本地没有的 → 新建
- 本地有的但文件夹不对 → 移动
- 本地有但云端没有的 → 删除

因为是逐条增量操作，**可以跟 Chrome/Edge 自带的书签同步并存**，
不会触发浏览器同步的批量事件干扰。

### ETag 并发保护

如果你在 Chrome 上点了同步，同时 Edge 的后台定时同步也触发了——后到的那个会被 ETag 阻止：

```
Chrome 同步 → PUT(XBEL, ETag:"v1") → ✅ OK，云端 ETag 变为 "v2"
Edge 同步   → PUT(XBEL, ETag:"v1") → ❌ 412 拒绝
                                     → 弹窗提示"云端已被修改，请重新同步"
```

这防止了**你以为同步成功了、实际上把别人的更新覆盖了**的静默丢数据。

## 安装

1. 下载整个文件夹
2. Chrome 打开 `chrome://extensions/`，开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本文件夹
4. Firefox：`about:debugging#/runtime/this-firefox` → 「临时载入附加组件」

---

## 使用（以 123 云盘为例）

1. 在 123 云盘 WebDAV 里新建文件 `bookmarks.xbel`（必须是文件，不能是目录）
2. 插件里填完整地址：
   ```
   https://webdav.123pan.cn/webdav/bookmarks.xbel
   ```
3. 输入账号密码
4. 保存配置 → 测试连接
5. 点「同步」

**重要**：URL 必须指向**具体文件**（.xbel），不能只到文件夹，否则会报 405。

### 多设备接入

```
设备 A（已有书签）：
  点「推送本地到云端」→ 把你的书签发到云端

设备 B（新设备）：
  点「从云端拉取」→ 书签出现在 B 上

之后日常使用：
  任意设备点「同步」即可（或等 60 分钟自动同步）
```

**建议关掉** Chrome / Edge 自带的书签同步和 iCloud 书签同步，否则它们会和本扩展互相覆盖。

## 为什么用 XBEL 而不是 HTML？

- XBEL 是标准书签交换格式（与 Floccus 兼容）
- 结构化更好，文件夹层次保留完整
- 跨浏览器导入导出更可靠

---

## 安全保障

| 机制 | 说明 |
|------|------|
| **ETag 乐观锁** | PUT 携带 `If-Match`，并发修改返回 412 而非静默覆盖 |
| **云端备份** | 每次写回前自动创建 `bookmarks.backup.xbel` |
| **关闭保护** | 同步进行中关闭弹窗会弹出确认提示 |
| **后台定时同步** | Service Worker 每 60 分钟自动同步一次 |

## 隐私

- 所有数据仅在你的浏览器和指定的 WebDAV 之间传输
- 无任何硬编码密码、Token 或个人信息
- 凭证保存在 `chrome.storage.local`
